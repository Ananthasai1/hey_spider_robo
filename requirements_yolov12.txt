# ============================================================================
# Installation Notes
# ============================================================================
# 1. Install system dependencies first:
#    sudo apt update && sudo apt install -y python3-pip python3-venv \
#    libcamera-dev python3-picamera2 portaudio19-dev espeak i2c-tools
#
# 2. Create virtual environment:
#    python3 -m venv venv
#    source venv/bin/activate
#
# 3. Install requirements:
#    pip install -r requirements.txt
#
# 4. Download YOLO models:
#    python -c "from ultralytics import YOLO; YOLO('yolov8n.pt')"

# ============================================================================
# Memory Requirements
# ============================================================================
# Minimum: 2GB RAM (with swap)
# Recommended: 4GB+ RAM
# Model sizes:
# - Nano (n): ~6MB, fastest, 30+ FPS on Pi 4
# - Small (s): ~22MB, balanced, 15-20 FPS on Pi 4
# - Medium (m): ~52MB, accurate, 8-12 FPS on Pi 4

# ============================================================================
# Performance Expectations (Raspberry Pi 4)
# ============================================================================
# YOLOv8n @ 640x640: ~25-30 FPS
# YOLOv8n @ 320x320: ~40-50 FPS (lower accuracy)
# YOLOv8s @ 640x640: ~15-20 FPS
# YOLOv8m @ 640x640: ~8-12 FPS
# 
# With camera capture + detection + tracking:
# - Expected overall FPS: 15-25 FPS (balanced preset)
# - Night vision may reduce FPS by 10-20%

# ============================================================================
# Troubleshooting
# ============================================================================
# If installation fails:
# 1. Ensure all system packages are installed
# 2. Try installing packages individually
# 3. Check Python version: python3 --version (need 3.8+)
# 4. Update pip: pip install --upgrade pip
# 5. Check available RAM: free -h
# 6. Consider creating swap: sudo fallocate -l 2G /swapfile
